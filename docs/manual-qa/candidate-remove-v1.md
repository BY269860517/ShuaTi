# 候选题移除 v1 手工验收

## 功能目标

本轮验收确认“解析结果页移除候选题”能力可用，重点验证：

- 用户可以在 PDF 解析结果页移除未导入的候选题。
- 已移除候选题不会在后续确认导入时进入题库。
- 移除候选题不会修改、删除或影响原 PDF 文件。
- 移除候选题不会影响已经导入题库的题目。
- 已进入 `importing` 或 `imported` 状态的候选题不展示移除入口，避免误删导入中或已导入数据。

## 上线/本地验证前准备

验证前请先确认 HBuilderX / uniCloud 环境已完成以下同步或上传：

1. 上传或同步公共模块 `common/shuati-shared`。
2. 上传云函数 `candidateDelete`。
3. 上传云函数 `candidateList`。
4. 上传云函数 `importConfirm`。
5. 同步数据库 schema，确认 `parse_candidates` 已包含 `deletedAt` 字段。
6. 使用最新本地包、体验版或线上版本验证；如使用微信体验版，请重新扫码进入，避免旧体验版缓存影响结果。

## 验收数据准备

1. 准备一个可正常解析出多道候选题的 PDF。
2. 进入 PDF 解析结果页，确认候选题列表中至少包含：
   - 1 道不可导入候选题，例如解析不完整、缺少必要字段或校验失败的题目。
   - 1 道可导入候选题。
3. 如当前 PDF 已全部导入或候选题过少，请重新上传新的测试 PDF。

## 验收步骤

### 1. 取消移除

1. 在解析结果页选择一条未导入候选题。
2. 点击“移除”入口。
3. 在确认弹窗中选择取消。
4. 返回列表后观察该候选题。

预期结果：

- 候选题仍显示在解析结果页。
- 候选题状态、内容、可导入性不变。
- 后续仍可继续移除或导入。

### 2. 确认移除不可导入题

1. 找到一条不可导入候选题。
2. 点击“移除”入口。
3. 在确认弹窗中确认移除。
4. 等待列表刷新。

预期结果：

- 该不可导入候选题从解析结果页消失。
- 页面不再提示该题阻塞导入。
- 原 PDF 仍可打开或查看。
- 其他候选题仍正常显示。

### 3. 确认移除可导入题

1. 找到一条可导入候选题，记录题干关键字，便于后续核对。
2. 点击“移除”入口。
3. 在确认弹窗中确认移除。
4. 等待列表刷新。

预期结果：

- 该可导入候选题从解析结果页消失。
- 其他可导入候选题仍可继续导入。
- 页面无异常报错、空白或卡死。

### 4. 导入后验证已移除题不进入题库

1. 在同一解析结果页点击确认导入。
2. 等待导入完成。
3. 进入题库、练习入口或对应题目列表。
4. 使用前面记录的已移除题题干关键字进行查找。

预期结果：

- 已移除候选题没有进入题库。
- 未移除且满足导入条件的候选题正常进入题库。
- 已导入题目可正常查看、练习或出现在对应列表中。
- 原 PDF 文件仍存在，不因候选题移除或导入操作被删除。

### 5. `importing` / `imported` 不显示移除

1. 找到已经处于导入中或已导入状态的候选题记录。
2. 返回解析结果页或刷新候选题列表。
3. 观察这些记录是否出现移除入口。

预期结果：

- `importing` 状态候选题不显示移除入口。
- `imported` 状态候选题不显示移除入口。
- 已导入题库的题目不受候选题移除功能影响。

## 失败排查

### 点击移除提示云函数不存在或网络错误

可能原因：`candidateDelete` 未上传。

处理方式：

- 在 HBuilderX 中上传云函数 `candidateDelete`。
- 上传后重新运行或刷新小程序，再次验证。

### 移除后列表不刷新、导入仍包含已移除题

可能原因：公共模块 `common/shuati-shared` 未上传，或 `candidateList` / `importConfirm` 仍是旧版本。

处理方式：

- 上传或同步 `common/shuati-shared`。
- 上传云函数 `candidateList`。
- 上传云函数 `importConfirm`。
- 重新进入解析结果页后再次验证。

### 移除时报字段不存在、数据库写入失败

可能原因：`parse_candidates` schema 未同步 `deletedAt` 字段。

处理方式：

- 在 uniCloud 数据库 schema 中同步 `parse_candidates`。
- 确认存在 `deletedAt` 字段。
- 重新执行移除操作。

### 本地正常，体验版仍是旧表现

可能原因：微信体验版未刷新或仍在使用旧包。

处理方式：

- 重新上传体验版。
- 在微信中删除旧体验版入口后重新扫码进入。
- 必要时清理小程序缓存，再重新打开验证。

## 通过标准

满足以下条件即可判定“候选题移除 v1”通过手工验收：

- 未导入候选题可以在解析结果页发起移除。
- 取消移除不会改变候选题状态或列表内容。
- 确认移除后，目标候选题从解析结果页消失。
- 已移除候选题不会进入题库。
- 未移除的可导入候选题仍可正常导入题库。
- 原 PDF 文件不受移除操作影响。
- 已经导入题库的题目不受移除操作影响。
- `importing` 和 `imported` 状态候选题不展示移除入口。
- 验收过程中无异常报错、空白页、卡死或明显数据错乱。
