## 验收目标

- 上传 PDF 页面展示清晰说明：文件大小不超过 20MB、当前支持单选题/多选题/判断题、题目必须有选项和标准答案。

## HBuilderX / 微信开发者工具操作步骤

1. 在 HBuilderX 中打开项目，点击工具栏“运行”。
2. 选择“运行到小程序模拟器”，再选择“微信开发者工具”。
3. 微信开发者工具启动后，等待小程序编译完成。
4. 在模拟器中进入“我的资料”页面。
5. 点击“上传 PDF”，进入上传页面。

## 验收场景

### 1. 上传页提示文案

操作步骤：

1. 进入“上传 PDF”页面。
2. 查看选择文件区域下方的说明文案。

预期结果：

- 页面能看到“文件大小不超过 20MB”。
- 页面能看到“目前支持单选题、多选题、判断题”。
- 页面能看到“题目必须有选项和标准答案”相关说明。
- 说明文字不遮挡文件信息、选择按钮或“上传并解析”按钮。

### 2. 大于 20MB PDF 被前端拦截

操作步骤：

1. 点击“选择 PDF”。
2. 在文件选择器中选择任意大于 20MB 的 PDF。
3. 观察上传页面状态。
4. 如微信开发者工具网络面板可用，观察是否出现 `uniCloud.uploadFile` 相关上传请求。

预期结果：

- 页面显示文件大小不能超过 20MB 的错误提示。
- 页面不展示该大文件的文件名和文件大小。
- “上传并解析”按钮保持不可点击状态。
- 不发起 `uniCloud.uploadFile` 上传请求。

### 3. 小于或等于 20MB PDF 正常上传解析

操作步骤：

1. 点击“选择 PDF”。
2. 选择 `doc/shuati-test-sample.pdf`，或任意小于或等于 20MB 的有效 PDF。
3. 确认页面展示文件名和文件大小。
4. 点击“上传并解析”。
5. 等待上传请求完成，并返回“我的资料”或资料详情相关页面。

预期结果：

- 页面展示已选 PDF 的文件名和文件大小。
- “上传并解析”按钮可点击。
- 点击后按原有流程上传文件、创建资料并触发解析。
- 上传过程中没有前端白屏、卡死或未捕获错误。
- 资料列表或详情中能看到新创建资料，解析状态与原有流程一致。

### 4. 解析算法不变确认

操作步骤：

1. 使用本次正常上传的 PDF 查看资料解析结果。
2. 对比改动前已有的解析行为和页面状态。
3. 如解析结果进入待审核、解析中、可刷题或解析失败，按原有状态流转标准判断。

预期结果：

- 本次改动不引入新的题型识别规则。
- 本次改动不改变 PDF 文本抽取、题目切分、答案识别或审核逻辑。
- 大文件拦截只发生在上传前，不影响已上传文件的后续解析链路。

## 通过标准

- 上传页面提示文案完整、可读，不挤压主要操作区域。
- 大于 20MB 的 PDF 在前端被拦截，不进入已选文件状态，不发起上传。
- 小于或等于 20MB 的 PDF 可以继续按原流程上传解析。
- 验收过程中未发现解析算法、题型识别或资料状态流转被本次改动改变。
