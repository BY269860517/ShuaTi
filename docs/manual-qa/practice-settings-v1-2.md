# 练习设置增强 v1.2 手工验收

## 验收目标

本轮验收确认“创建练习”页面的练习设置可用，并且设置能正确影响后续练习题目范围与出题顺序。重点覆盖：

- 固定题量：默认或固定数量创建练习时，题目数量符合页面展示和后端返回。
- 全部练习：选择全部题目时，系统尽量纳入当前条件下的所有可练习题目。
- 自定义题数：用户输入指定题数后，创建出的练习题数符合输入值或可用题目上限。
- 顺序 / 随机：顺序模式保持题库原有顺序，随机模式多次创建时题目顺序或题目集合有变化。
- 全部 / 未练习：全部范围包含已练和未练题目，未练习范围只使用当前用户未练过的题目。
- 题型筛选：选择单选、多选、判断后，只创建匹配题型的练习。

## 验收前准备

在 HBuilderX / uniCloud 环境中先完成以下同步或上传：

1. 上传或同步公共模块 `common/shuati-shared`。
2. 上传云函数 `practiceCreate`。
3. 上传云函数 `practiceDetail`。
4. 上传云函数 `answerSubmit`。
5. 同步数据库 schema：`practice_sessions`。
6. 在 uniCloud 数据库 schema 中确认 `practice_sessions` 已包含以下字段：
   - `countMode`
   - `requestedCount`
   - `orderMode`
   - `scope`
   - `questionType`

测试数据准备：

1. 准备一个已成功导入题库的资料，题目总数建议不少于 10 道。
2. 题库中建议至少包含 2 种题型，例如单选题、判断题或多选题。
3. 如需验收“未练习题目”，请准备一个新账号，或使用一个还没有练过该资料全部题目的账号。
4. 如需验收“无未练习题目”，请使用同一账号先完成当前资料下的全部题目。
5. 使用最新本地包、体验版或线上版本验证；如使用微信体验版，请重新扫码进入，避免旧包缓存影响结果。

## 验收步骤

### 1. 全部练习

操作步骤：

1. 打开已导入完成的资料详情页。
2. 进入创建练习页面。
3. 题量模式选择“全部练习”。
4. 范围选择“全部题目”。
5. 题型选择“全部题型”。
6. 出题顺序选择“顺序”。
7. 点击开始练习。

预期结果：

- 可以正常进入练习页面。
- 练习题数等于当前资料在“全部题目 + 全部题型”条件下的可练习题数。
- 第一题和后续题目按资料题库顺序展示。
- 练习过程中提交答案、切换下一题、完成练习均无报错。

### 2. 自定义题数

操作步骤：

1. 返回创建练习页面。
2. 题量模式选择“自定义题数”。
3. 输入一个小于可用题目总数的数字，例如 `5`。
4. 范围选择“全部题目”。
5. 题型选择“全部题型”。
6. 点击开始练习。

预期结果：

- 可以正常创建并进入练习。
- 本次练习总题数等于输入的自定义题数。
- 练习详情、答题页进度、完成页统计中的总题数保持一致。

补充验证：

1. 再次输入一个大于可用题目总数的数字。
2. 点击开始练习。

预期结果：

- 系统不应创建超过可用题目数量的练习。
- 如产品设计为自动截断，则练习题数等于可用题目总数。
- 如产品设计为阻止创建，则页面应给出清晰提示，不能出现空白页或卡死。

### 3. 题型筛选

操作步骤：

1. 在创建练习页面选择一个当前资料中存在的题型，例如“单选题”。
2. 题量模式可选择“全部练习”或输入一个较小的自定义题数。
3. 范围选择“全部题目”。
4. 点击开始练习。
5. 在练习页逐题查看题目类型。

预期结果：

- 可以正常进入练习页面。
- 本次练习中只出现所选题型。
- 不应混入未选择的题型。
- 练习详情和答题提交流程正常。

### 4. 未练习题目

操作步骤：

1. 使用存在部分已练记录、但仍有未练题目的账号。
2. 进入创建练习页面。
3. 范围选择“未练习题目”。
4. 题型选择“全部题型”。
5. 题量模式选择“全部练习”。
6. 点击开始练习。

预期结果：

- 可以正常进入练习页面。
- 本次练习只包含当前账号未练过的题目。
- 已经在历史练习中提交过答案的题目不应再次出现。
- 完成本次练习后，再次创建“未练习题目”练习时，可用未练题数会减少。

### 5. 随机出题

操作步骤：

1. 进入创建练习页面。
2. 题量模式选择“自定义题数”，输入小于可用题目总数的数字，例如 `5`。
3. 范围选择“全部题目”。
4. 题型选择“全部题型”。
5. 出题顺序选择“随机”。
6. 创建一次练习，记录本次题目顺序或前几道题题干关键词。
7. 返回创建练习页面，保持相同设置，再创建一次练习。

预期结果：

- 两次练习都可以正常创建。
- 在题库数量足够时，两次练习的题目顺序或题目集合应有明显差异。
- 随机模式下仍然遵守题量、范围、题型筛选条件。
- 不应出现重复题目导致同一次练习题数不足。

### 6. 无匹配题型

操作步骤：

1. 选择一个当前资料中不存在的题型。
2. 范围选择“全部题目”。
3. 题量模式选择“全部练习”。
4. 点击开始练习。

预期结果：

- 系统不应创建空练习。
- 页面应提示没有匹配题目或当前题型暂无可练习题目。
- 用户停留在创建练习页面，或可返回重新选择题型。
- 不应进入空白答题页、异常详情页或出现未处理报错。

### 7. 无未练习题目

操作步骤：

1. 使用已经练完当前资料全部题目的账号。
2. 进入创建练习页面。
3. 范围选择“未练习题目”。
4. 题型选择“全部题型”。
5. 点击开始练习。

预期结果：

- 系统不应创建空练习。
- 页面应提示当前没有未练习题目，或提示该范围下暂无可练习内容。
- 用户可以修改范围为“全部题目”后重新创建练习。
- 不应出现空白页、卡死、进度为 `0/0` 的答题页或云函数未处理错误。

## 通过标准

满足以下条件即可判定“练习设置增强 v1.2”通过手工验收：

- 全部练习、自定义题数、顺序出题、随机出题均可正常创建练习。
- 自定义题数不会超过当前筛选条件下的可用题目数量。
- “全部题目”和“未练习题目”范围生效，且不会互相混淆。
- 题型筛选生效，练习中不会混入未选择题型。
- 随机出题遵守题量、范围、题型条件，并且多次创建存在随机差异。
- 无匹配题型、无未练习题目时有明确错误提示，不创建空练习。
- `practice_sessions` 中能记录本次练习设置，包括 `countMode`、`requestedCount`、`orderMode`、`scope`、`questionType`。
- 答题、提交、下一题、完成练习、查看结果等既有流程不受影响。
- 验收过程中无空白页、卡死、明显数据错乱或未处理异常。

## 常见失败排查

### 创建练习提示云函数不存在或网络错误

可能原因：`practiceCreate` 未上传，或体验版仍在使用旧云函数。

处理方式：

- 在 HBuilderX 中上传云函数 `practiceCreate`。
- 重新运行本地小程序或重新上传体验版。
- 重新扫码进入体验版后再验证。

### 创建成功但题量、范围、题型不生效

可能原因：公共模块 `common/shuati-shared` 未同步，云端仍使用旧的练习创建逻辑。

处理方式：

- 上传或同步 `common/shuati-shared`。
- 重新上传 `practiceCreate`。
- 清理小程序缓存或重新进入后再验证。

### 进入练习详情失败或设置字段丢失

可能原因：`practiceDetail` 未上传，或 `practice_sessions` schema 未同步新字段。

处理方式：

- 上传云函数 `practiceDetail`。
- 同步数据库 schema `practice_sessions`。
- 确认 `countMode`、`requestedCount`、`orderMode`、`scope`、`questionType` 字段存在。

### 提交答案失败，未练习范围不更新

可能原因：`answerSubmit` 未上传，或答题记录未正确写入。

处理方式：

- 上传云函数 `answerSubmit`。
- 完成一次普通练习后，重新创建“未练习题目”练习验证范围是否变化。
- 如仍不变化，检查云函数日志中是否有答题记录写入失败。

### 随机出题看起来没有变化

可能原因：题库题目太少，或自定义题数接近可用题目总数。

处理方式：

- 使用题目数量更多的资料重新验证。
- 将自定义题数设置为小于可用题目总数，例如总数 20 道时选择 5 道。
- 连续创建 3 次练习，对比题目顺序和题目集合。

### 无匹配题型或无未练习题目时进入空白练习

可能原因：前端未拦截空结果，或 `practiceCreate` 没有返回清晰错误。

处理方式：

- 确认 `practiceCreate` 已上传最新版本。
- 确认前端使用最新包或体验版。
- 查看云函数日志，确认返回的是“暂无可练习题目”类错误，而不是空 session。
