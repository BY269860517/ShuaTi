## 验收场景

### 1. 删除解析失败资料

操作步骤：

1. 打开首页“我的资料”。
2. 找到状态为“解析失败”的资料。
3. 点击资料卡片上的“删除”按钮。
4. 在确认弹窗中点击“删除”。

预期结果：

- 资料卡片从首页列表中消失。
- 刷新首页后，该资料仍不再出现。
- 云数据库 `materials` 中该记录仍存在，但 `deletedAt` 有值。
- 页面不出现白屏、卡死或未捕获错误提示。

### 2. 删除可刷题资料

操作步骤：

1. 打开首页“我的资料”。
2. 找到状态为“可刷题”的资料。
3. 点击资料卡片上的“删除”按钮。
4. 阅读确认弹窗文案，确认其说明历史题目、练习记录和错题记录会保留。
5. 在确认弹窗中点击“删除”。

预期结果：

- 首页不再展示该资料。
- 刷新首页后，该资料仍不再出现。
- 删除动作不会物理清理题目、历史练习记录或错题记录。
- 云函数调用成功，不出现权限错误或数据库 schema 错误。

### 3. 取消删除

操作步骤：

1. 点击任意资料卡片上的“删除”按钮。
2. 在确认弹窗中点击“取消”。

预期结果：

- 资料仍然保留在首页列表中。
- 页面不展示“已删除资料”提示。
- 不应触发 `materialDelete` 云函数请求。
- 刷新首页后，该资料仍正常显示。

### 4. 删除中防重复点击

操作步骤：

1. 点击资料卡片上的“删除”按钮。
2. 在确认弹窗中点击“删除”。
3. 删除请求完成前，观察当前卡片删除按钮状态，并尝试重复点击。

预期结果：

- 当前卡片按钮进入删除中或禁用状态。
- 重复点击不会发起多个删除请求。
- 删除成功后，资料卡片从列表中移除。
- 删除失败时，按钮状态恢复，并展示可理解的失败提示。
