# 微信广告接入 v1 使用与手工验收

## 接入范围

- 首页资料列表：在第 2 个资料卡片后展示 1 个信息流/Banner 广告。
- 练习结果页：在成绩卡片下方、操作按钮上方展示 1 个信息流/Banner 广告。
- 答题页不放广告，避免打断刷题流程。
- 本版本不接入插屏广告和激励视频广告。
- 广告默认关闭，必须拿到真实微信广告位 ID 后再开启。

## 在微信公众平台创建广告位

1. 登录微信公众平台，进入 ShuaTi 对应的小程序。
2. 进入「流量主」或「广告与服务」相关入口。
3. 按平台提示开通流量主能力后，进入广告位管理。
4. 创建两个广告位：
   - 结果页广告位：用于练习结果页。
   - 首页广告位：用于首页资料列表。
5. 保存微信后台生成的两个广告位 ID。广告位 ID 通常形如 `adunit-xxxxxxxxxxxxxxxx`，必须以微信后台实际生成值为准。

## 填入项目配置

打开 `common/ad/config.ts`，把两个广告位 ID 填入对应字段，并把 `enabled` 改为 `true`：

```ts
export const AD_CONFIG: {
  enabled: boolean
  resultFeedUnitId: string
  homeFeedUnitId: string
} = {
  enabled: true,
  resultFeedUnitId: 'adunit-替换为练习结果页广告位ID',
  homeFeedUnitId: 'adunit-替换为首页资料列表广告位ID',
}
```

注意事项：

- 不要把结果页广告位 ID 和首页广告位 ID 填反。
- 没有真实广告位 ID 时保持 `enabled: false`，避免线上出现无效广告容器。
- `enabled: true` 但广告位 ID 为空时，对应广告不会展示。

## 首页手工验收

1. 使用 HBuilderX 运行到微信开发者工具，或使用构建产物导入微信开发者工具。
2. 确认 `common/ad/config.ts` 中 `enabled` 为 `true`，且 `homeFeedUnitId` 已填入形如 `adunit-xxx` 的真实广告位 ID。
3. 准备至少 2 个资料条目。
4. 进入首页资料列表。
5. 确认第 2 个资料卡片后出现广告区域。
6. 继续点击资料卡片、删除资料、进入练习等首页主流程，确认广告加载状态不影响页面操作。

## 结果页手工验收

1. 确认 `common/ad/config.ts` 中 `enabled` 为 `true`，且 `resultFeedUnitId` 已填入形如 `adunit-xxx` 的真实广告位 ID。
2. 从首页进入任意资料并完成一次练习。
3. 进入练习结果页。
4. 确认广告区域位于成绩卡片下方、操作按钮上方。
5. 点击结果页操作按钮，例如重新练习、返回首页等，确认主流程可正常继续。

## 失败降级验收

- 如果广告加载失败，微信开发者工具 Console 可能出现广告相关错误码或错误信息。
- 广告加载失败只允许影响广告展示，不应影响首页资料列表、练习结果页按钮、返回首页、重新练习等主流程。
- 网络异常、无广告填充、广告位审核中等情况，都不应导致页面白屏或阻塞用户刷题。

## 答题页验收

1. 进入任意资料的答题页。
2. 确认题目、选项、进度和提交操作区域中不出现广告。
3. 连续答题时不应出现插屏广告、激励视频广告或任何打断式广告。

## 通过标准

- 微信公众平台已创建两个广告位，并拿到形如 `adunit-xxx` 的广告位 ID。
- `common/ad/config.ts` 中两个广告位 ID 填写正确，`enabled` 已按上线目标改为 `true`。
- 首页广告只出现在第 2 个资料卡片后。
- 结果页广告只出现在成绩卡片下方、操作按钮上方。
- 答题页不展示广告。
- 广告加载失败不影响刷题、结果页操作和首页资料列表等主流程。
