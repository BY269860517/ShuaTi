## 验收场景

### 1. 答错后自动进入错题本

操作步骤：

1. 导入一个 PDF，并创建一次普通练习。
2. 在练习中故意答错一道题。
3. 完成练习，进入练习结果页。
4. 点击“查看错题”。

预期结果：

- 可以正常进入错题列表页。
- 刚才答错的题目出现在错题列表中。
- 该题的 `wrongCount` 为 `1`。
- 该题的 `correctStreak` 为 `0`。

### 2. 重复提交不会重复加入同一道错题

操作步骤：

1. 在已经答过的题目上，如果界面允许再次提交，尝试重复提交一次；或者刷新后重新进入同一练习结果。
2. 再次打开错题列表页。

预期结果：

- 同一道题在错题列表中只出现一次。
- 同一次练习中的重复提交不会让 `wrongCount` 异常增加。

### 3. 错题练习复用普通练习页面

操作步骤：

1. 打开“我的”页面。
2. 点击“查看错题”。
3. 在错题列表页点击“练习错题”。

预期结果：

- 小程序跳转到 `pages/practice/do` 练习页面。
- 错题使用普通题库练习的题目卡片样式展示。
- 提交答案前，不展示正确答案和解析。
- 提交答案后，展示正确答案和解析。

### 4. 连续答对三次后移出活跃错题

操作步骤：

1. 针对同一道错题，多次创建错题练习。
2. 在不同练习中连续答对该题三次。
3. 再次打开错题列表页。

预期结果：
云数据库中该错题记录的状态变为 `mastered`。
