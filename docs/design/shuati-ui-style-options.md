# ShuaTi UI 风格方案选择

> 目的：先确定整套视觉方向，再进入实施计划。此文档只讨论 UI 风格，不改业务逻辑、不改云函数、不调整功能范围。

## 当前 UI 基线

- 技术栈：uni-app + Vue 3 + TypeScript，面向微信小程序。
- 当前视觉：浅灰背景、白色卡片、8rpx 圆角、蓝色主按钮。
- 当前问题：整体可用但偏“后台表单感”，学习 App 的层次、进度感、状态识别还不够强。
- 改版原则：保留现有信息结构和交互路径，只统一视觉语言、间距、按钮、标签、卡片、进度和题目状态。

## 方案 A：清爽学习工具型

**定位：推荐方案。** 像一个专注刷题的小工具，安静、清晰、适合长期使用。

- 主色：深湖蓝 `#246D9D`
- 辅色：青绿 `#1F9D7A`
- 背景：冷白灰 `#F5F8FB`
- 卡片：白底，轻边框，弱阴影
- 圆角：8rpx，保持克制
- 适合页面：首页资料、练习设置、答题页、错题本
- 优点：最稳、最专业、广告位也不突兀
- 风险：视觉冲击不强，但对工具类产品是好事

## 方案 B：考试冲刺高对比型

适合强调效率、冲刺、考试感，视觉更有动力。

- 主色：靛蓝 `#2643A2`
- 辅色：橙色 `#F59E0B`
- 背景：微冷蓝灰 `#F3F6FC`
- 卡片：更强分区，更明显的进度和状态
- 圆角：8rpx，按钮更厚重
- 适合页面：练习设置、答题页、结果页
- 优点：更有“备考产品”的感觉
- 风险：状态色和广告色容易抢注意力，需要控制橙色用量

## 方案 C：轻量成长记录型

适合偏温和、陪伴、每日刷题记录的产品气质。

- 主色：墨绿 `#2F7D5B`
- 辅色：雾蓝 `#5B7FA6`
- 背景：暖白 `#F7F7F2`
- 卡片：柔和边框，进度块更明显
- 圆角：8rpx，避免过度圆润
- 适合页面：我的页面、错题本、学习记录
- 优点：亲和，适合长期留存
- 风险：如果处理不好会偏“日记/打卡”，不如 A 适合题库效率场景

## 我的建议

选 **A：清爽学习工具型**。

理由：

- ShuaTi 目前核心是 PDF 导入、题库练习、错题本，用户主要目标是完成任务，不是浏览内容。
- A 可以在不动逻辑的情况下显著提升专业感。
- A 的颜色和布局更容易兼容后续广告位，不会显得廉价。
- A 也最容易渐进式落地：先改全局视觉 token，再改核心页面，不需要重写组件体系。

## 选择后实施范围

选定方案后，建议按页面分批落地：

1. 全局视觉 token：颜色、字体层级、卡片、按钮、标签、状态色。
2. 首页资料卡：资料状态、已刷进度、删除按钮、广告位间距。
3. 练习设置页：选项按钮、题型筛选、底部按钮。
4. 答题页：题干、选项、提交后状态。
5. 错题本：规则说明、错题卡、标记已掌握。
6. 结果页：得分、错题入口、广告位。
