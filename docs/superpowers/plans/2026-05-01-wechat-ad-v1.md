# WeChat Ad Monetization v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 ShuaTi 微信小程序接入第一版广告位：练习结果页广告和首页资料列表广告。

**Architecture:** 广告 ID 统一放在 `common/ad/config.ts`，页面不直接写死广告位 ID。新增 `components/AppAd.vue` 包装微信小程序 `<ad>` 组件，默认广告关闭，只有 `AD_CONFIG.enabled === true` 且对应广告位 ID 不为空时才渲染。第一版只做信息流/Banner 广告，不接入插屏和激励视频，避免打断刷题流程。

**Tech Stack:** uni-app Vue 3 `<script setup lang="ts">`、微信小程序 `<ad>` 组件、TypeScript、Vitest/Bun、HBuilderX 微信小程序构建。

---

## File Structure

- Create: `common/ad/config.ts`
  - 统一管理广告开关和两个微信广告位 ID。
  - 默认 `enabled: false`，避免未配置广告位时线上展示空白广告容器。
- Create: `components/AppAd.vue`
  - 只在 `MP-WEIXIN` 条件编译下渲染 `<ad>`。
  - `unitId` 为空时不渲染。
  - 广告加载失败只记录日志，不影响主流程。
- Modify: `pages/practice/result.vue`
  - 在成绩卡片下方、按钮组上方放置结果页广告。
- Modify: `pages/index/index.vue`
  - 在资料列表第 2 个资料卡后插入首页广告。
  - 资料不足 2 个或广告位未配置时不显示。
- Create: `tests/frontend/adPlacements.spec.ts`
  - 用源码断言锁住广告配置、组件条件编译、结果页位置和首页列表位置。
- Create: `docs/manual-qa/wechat-ad-v1.md`
  - 中文接入说明和手工验收步骤。

```md
# 微信广告接入 v1 使用与验收说明

## 本次接入范围

- 首页资料列表：第 2 个资料卡后展示一个信息流/Banner 广告。
- 练习结果页：成绩卡片下方、操作按钮上方展示一个信息流/Banner 广告。
- 暂不接入答题页广告、插屏广告、激励视频广告。
- 默认广告关闭，拿到真实广告位 ID 后再开启。

## 创建微信广告位

1. 登录微信公众平台，进入对应小程序。
2. 进入“流量主”或“广告与服务”。
3. 开通流量主后进入广告管理。
4. 新建两个广告位：
   - `result_feed_ad`：用于练习结果页。
   - `home_feed_ad`：用于首页资料列表。
5. 复制微信后台生成的广告位 ID，通常形如 `adunit-xxxxxxxxxxxxxxxx`。

## 填入项目配置

打开 `common/ad/config.ts`，把配置改成：

```ts
export const AD_CONFIG: {
  enabled: boolean
  resultFeedUnitId: string
  homeFeedUnitId: string
} = {
  enabled: true,
  resultFeedUnitId: 'adunit-这里替换为练习结果页广告位ID',
  homeFeedUnitId: 'adunit-这里替换为首页资料列表广告位ID',
}
```

## 发布前验证

1. 在 HBuilderX 中运行到微信开发者工具。
2. 首页资料列表至少准备 2 个资料。
3. 确认第 2 个资料卡后出现广告区域。
4. 完成一次练习，进入结果页。
5. 确认成绩卡片下方、按钮上方出现广告区域。
6. 如果广告没有填充，查看微信开发者工具 Console 中的广告错误码；广告未填充不应影响页面按钮和刷题流程。

## 通过标准

- `enabled: false` 时，首页和结果页不出现空白广告容器。
- `enabled: true` 且广告位 ID 正确时，广告组件出现在指定位置。
- 广告加载失败不影响首页资料列表、练习结果页按钮和返回流程。
- 答题页面不出现广告。
```
